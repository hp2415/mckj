上传 XLSX，按本地主键 id 绑定主系统规格 ID（mibuddy_sp_id）。 历史表头「成本价」列现视为规格 ID，导入时会清洗空值、#N/A、科学计数法以及被 Excel 转成数字的超长 ID。 空/#N/A 行会跳过，不会清空已有规格 ID。导入成功后会立即按本次绑定的 ID 刷新成本价；主系统未返回的规格 ID 会单独列出，便于核对修改。
